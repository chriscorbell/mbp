# Shortcuts Automations

Shortcuts automations cannot be exported or installed from the CLI. Recreate them by hand in the Shortcuts app from the specs below.

## Rename Screenshot from Image Content

Watches the Screenshots folder and renames each new screenshot to a descriptive filename generated by ChatGPT from the image content.

Prerequisites:

- Screenshot location set to `~/Pictures/Screenshots` (see `docs/macos-settings.md` > Screenshots)
- ChatGPT enabled as a model for Apple Intelligence (System Settings > Apple Intelligence & Siri > ChatGPT), since the shortcut uses the ChatGPT model in the Ask LLM action

### The shortcut

Create a shortcut named `Rename Screenshot from Image Content` with three actions:

1. **Detect Images** — input: `Shortcut Input` > `Added files`
2. **Ask LLM** (Use Model) — model: `ChatGPT`, output: text, prompt (with the Images output from step 1 attached at the start):

   > Provide a descriptive file name for this screenshot using good filenaming practices (concise, lowercase, underscores instead of spaces, etc) that accurately describes what's in the image.
   >
   > Examples: "personal_website_layout", "chatgpt_settings", "shortcuts_app_config"
   >
   > Output **ONLY** the descriptive filename - your output is being used in an automation flow where your output will become the new filename for this image file.

3. **Rename File** — file: `Shortcut Input` > `Added files`, new name: the `Response` output from step 2

### The automation

In Shortcuts > Automation, create a Folder automation:

- Folder: `~/Pictures/Screenshots`
- When: files are added (subfolders included)
- Run: `Rename Screenshot from Image Content`, Run Immediately (no confirmation), notifications off
